# Restrictor import - 2026-10-05

## Provenance and placement

Source: supplied `PCV-Restrictor` batch containing a README, native FreeCAD model, three 3MF files, and two PNG model views. Inbox originals were preserved. The public [component README](README.md) incorporates the useful design and printing notes while distinguishing intentions from verified geometry.

Native source is in `source/`; all three 3MF variants are together in `printing/`. The 2 mm file is a FreeCAD mesh export; the 3 and 4 mm files are QIDI Studio projects with print settings. Supplied views are in `media/diagrams/pcv-restrictor/`. The variants were consolidated on 2026-10-06 without changing file contents.
