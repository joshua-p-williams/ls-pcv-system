# Firmware feature workspaces

This folder contains the durable planning artifacts for each firmware milestone. A workspace is
named `<ID>-<short-slug>` so it can be cross-referenced from the [milestone roadmap](../milestones/README.md).
The term *feature* here includes foundational work such as establishing the development
environment; it describes a bounded work package, not necessarily a user-visible gauge capability.

Each workspace may begin with `brainstorm.md` while scope and behavior are being discussed. After
review, the five lifecycle documents are created one at a time in order: `feature.md`,
`research.md`, `architecture.md`, `plan.md`, and `tasks.md`. Follow the [Codex development
workflow](../developing-with-codex/README.md), including its review gates. A brainstorm is not a
feature specification or implementation authorization.
