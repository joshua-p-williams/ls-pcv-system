# Schematics and physical layouts

Follow the [standard](../../docs/diagramming-and-wiring-standard.md). Create `drawio/` with the first selected physical-layout illustration; use editable `.drawio.svg` with embedded diagram data. Use this only when spatial arrangement adds useful information beyond architecture and wiring.

A physical-layout illustration is not an electrical schematic or dimensional CAD authority. Circuit schematics, if needed, belong in a named circuit subdirectory with native KiCad files and reviewed exports. Analog conditioning or protection complexity may justify a schematic even without a custom PCB. No layout or circuit schematic has been created yet; see the [inventory](../DIAGRAMS.md).
